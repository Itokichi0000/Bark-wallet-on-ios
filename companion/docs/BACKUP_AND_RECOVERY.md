# バックアップと復元

## 前提（Second のドキュメントより）

- シードフレーズだけの復元は Ark サーバーの協力が必要で、履歴は戻らない。進行中の exit は限定的にしか再開できない。
- 完全な復元には、ウォレット DB の最新バックアップが必要。状態が変わるたびに取り、端末の外に置き、暗号化する。

## 実装

1. 送金・受取・作成などの状態変化で `BackupManager.stateChanged` → 1.5 秒まとめてから実行。
2. デーモンを止める → DB ファイルをコピー（journal / WAL が残っていたら中止して失敗扱い）→ デーモン再開。
3. 封緘して `Documents/backups/bcw-<fingerprint>-<世代>.bcwb` に保存。直近 5 世代を保持。
4. 「端末の外に保存する」で OS の共有シートに渡す。保存先はアプリから確認できないため、
   表示は「共有に出しました（保存先は確認できません）」に留める。

### ファイル形式 BCWB1

```
"BCWB1" | u32 ヘッダ長 | ヘッダ JSON | 24 バイト nonce | XChaCha20-Poly1305 暗号文
```

- 鍵 = HKDF-SHA256(BIP39 シード, ランダム 16 バイト salt, info = `bark-companion-wallet/db-backup/v1/<network>`)
- ヘッダ（network / fingerprint / 世代 / 作成時刻 / SDK 版）は平文だが AAD として認証される。
- 単体テスト: 往復、別シード拒否、改ざん検出（本文・ヘッダ）、切り詰め、ネットワーク束縛、危険なファイル名の拒否。

### 復元

- 空のデータ領域にだけ復元する。既存ウォレットは上書きしない（別ウォレット / 古い世代 / 同一でも拒否）。
- 復号 → ネットワーク確認 → 書き込み → `readDatadirInfo` で fingerprint 照合。合わなければ取り消す。

## 状態: 暗号部は verified、端末上の取得・復元は **untested**

設定画面にも「復元は実機で未検証」と表示しています。次の手順が通るまで、この表示は外さないでください。

1. Signet でウォレット作成、faucet から受取
2. 設定 → いまバックアップする → 端末の外に保存（ファイルアプリ等）
3. アプリを削除して入れ直す
4. 復元 → バックアップ＋シード → 残高・履歴・fingerprint が元と一致することを確認
5. 別のシードで復号できないこと、既存ウォレットがある状態で復元が拒否されることを確認
